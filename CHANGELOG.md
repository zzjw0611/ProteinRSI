- Integrate the delivered v0.3 isolated local tool layer; no NIM dependency.
- Add an actual limited Apache-2.0 adaptation of Biomni's category retriever,
  with injected budgeted JSON client and strict resource-index checks.
- Add permission-first resources, original snapshotted Know-how and scoped records.
- Add typed plans, bounded A revisions, completed-step checkpoints and explicit failures.
- Add observed-only QC, frozen prediction errors and explicit-scale combination diagnostics.

- Copy identical research configuration and Know-how into paired Meta offspring.
- Add research CLI/configuration, tests and a precise reuse/license inventory.
- Do not claim new model/GPU/LLM/wet-lab efficacy or unbounded code RSI.


## 0.3.0 — local function tools and isolated engine execution

- Separate 13 tool descriptions/JSON Schemas from their implementations; retain
  ESMC's three existing names and move their descriptions to the same registry.
- Add local ProteinMPNN, RFdiffusion, Protenix and optional licensed PyRosetta
  adapters; no NIM/cloud service and no mandatory MCP wrapper.
- Add sequence checks, PDB chain/residue maps, CA geometry/RMSD and A3M validation.
- Add per-engine process/Docker settings, source/asset pins, preflight/probe,
  artifact import, bounded job execution, credential stripping and failure logs.
- Add optional separate-interpreter ESMC backend; native mode remains supported.
- Add bounded sequential B tool rounds and C analysis-only tool rounds.
- Add unified operator configuration, setup-plan/pinning helpers and task-specific
  completeness/limitations documentation.
- Do not claim deployment, live GPU/model validation or quantitative affinity.
  Numerical Meta promotion explicitly refuses external-structure configurations
  until task-scoped evaluation provisioning is implemented.
