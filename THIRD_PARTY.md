# Licenses, provenance and reuse

## What the repository license covers

`LICENSE` (MIT) applies to ProteinRSI's **original source, tests, synthetic fixture generator and documentation**. Copyright: 2026 ProteinRSI contributors. No third-party Agent source files, model weights, experimental datasets or user research PDFs are vendored. Imports and API adapters do not relicense upstream packages.

The fixture generated by `synthetic.py` is artificial data produced by original code. It must not be redistributed with a claim that it is measured protein fitness.

Optional providers and service terms are separate from Python-package licenses. Development tooling keeps its own licenses.

## Protein-engine deployments

ProteinMCP (MIT wrapper) and protein-design-mcp (Apache-2.0 wrapper) may be used as separately installed services. Their wrapper licenses do not grant rights to every underlying engine, database or set of model weights. In particular, obtain any necessary Rosetta/PyRosetta/AlphaFold or other restricted assets from their licensors under the applicable terms. No restricted materials are packaged here. Inspect each exact upstream release and deployment asset before use.

## Architectural references, not vendored code

| Reference | Status in this repository |
|---|---|
| ProteinSwarm | Reference for direct sequence-edit/feedback design. Its source and scientific results are not copied or reproduced. |
| HyperAgents | Reference for making the improver itself evolvable. Its CC BY-NC-SA 4.0 source is **not included**, imported, or relicensed as MIT. ProteinRSI implements original bounded JSON policy evolution, not a fork of its coding agent. |
| ALDE / alde4ssmula | Reference and future external baseline. The included ridge baseline is original NumPy code, **not the ALDE implementation**. |
| SSMuLA / ProteinGym / other datasets | Optional user-supplied data only. The repository includes a normalization utility, not dataset content or a blanket data license. |
| BioNeMo Agent Toolkit | Reference for Skill organization; no toolkit scripts or model assets are vendored. |
| Biomni / ADAS / VenusFactory2 | Related architecture references, not runtime dependencies or copied code. |

Avoid describing the project as a source-level merger of these repositories. Actual reuse consists of library/API integrations listed above, plus optional independently deployed tool services. If a future contribution vendors upstream material, include its exact source revision, complete license and notices, modifications, and a compatibility review **before merging**. A citation does not substitute for permission, and this file does not override upstream terms.
