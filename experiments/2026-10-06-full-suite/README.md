# Live assistant replay: full-budget suite (partial, 4/16 complete)

Four independent landscapes have completed **20 rounds × 100 new queries**, with real assistant decisions, actual trusted tool execution, returned historical measurements, analysis, budgeted method comparisons, and durable restarts. This is historical assay replay, not new wet-lab measurements. Twelve landscapes remain in progress or queued. Do not interpret this intermediate selection as the full suite result.

## Results at the same query budget

Every live study and each separate comparator used 2,000 new query slots. Missing historical records consumed slots, without free membership checks or replacement. The parent is the same supplied initial observation for all policies. Scores below include that parent; units differ between landscapes and must not be pooled.

| TrpB3A | 1 | **1** | 1 | 1 | 1 | 1988 / 12 |

GB1 reached its recorded maximum in round 3 with V39F/D40W/G41A/V54A. ParD3 reached its recorded maximum in round 1 with K64W. T7 improved over its parent but lost to both comparators. TrpB3A did not improve over its parent; a terminal-only audit found no above-parent record in the supplied table. The agents did not receive these maximum or comparator audits while choosing candidates, and all completed the entire budget.

A single trajectory per policy and one comparator seed do **not** establish general superiority, reproducibility across LLM runs, or scientific RSI efficacy. This benchmark also cannot exclude prior knowledge of famous public landscapes in model pretraining. No unrevealed lookup labels were intentionally supplied to researchers.

## What actually ran

- Pinned engine: [`ff678883c496610458d179807b0a54443fd940fd`](https://github.com/zzjw0611/ProteinRSI/tree/ff678883c496610458d179807b0a54443fd940fd). Later reporting-only changes do not alter running engine snapshots.
- Separate fresh assistant context and mailbox per landscape. Each role response was written after an actual request; responses were not generated by a scripted/mock provider. The bridge's model name is an operator label, not independently authenticated API-model identity.
- Live charged calls: GB1 127 LLM / 4 tools; ParD3 125 / 3; T7 118 / 4; TrpB3A 115 / 2. No paid external model API was invoked. Provider token/cost figures are not available.
- All four: 20 completed plates, 2,000 distinct new identities, zero repeated queries, no outstanding reservations. Replaying the exact terminal command produced no new measurements, requests or charges; before/after hashes were checked by each operator.
- W comparisons were inconclusive and retained incumbents. The ParD3 and TrpB3A nested M comparisons rejected challengers. No method adoption occurred in these four full studies. The earlier separate ParD3 smoke did exercise adoption; it is not pooled into these results.
- Comparator proposal orders were frozen before oracle access. Their 4,000 additional queries per landscape are separate evaluation studies, not free training data for the live agent.

A null estimate is not a zero; a tool call alone does not freeze a prediction. The trusted artifact must flow through C ranking and final selection. GB1 round 3 used a B-only final response and therefore legitimately had no frozen estimates, even though a fit ran. Subsequent rounds used the supported typed path. No estimates were backfilled. ## Limits and remaining engineering work

The user approved **trusted inprocess debugging** here because this cloud kernel cannot supply the required Landlock sandbox. The guarded default still fails closed. Separately, [supported Ubuntu CI](https://github.com/zzjw0611/ProteinRSI/actions/runs/37449917139) reported Landlock ABI 7 and libseccomp, and ran 546 automated tests successfully with only two ESMC-related skips. This verifies guarded automated tests on that runner, but these live studies do not validate OS-level hidden-label isolation, untrusted generated Python execution, native remote-provider operation, heavy undeployed protein models, or real wet-lab infrastructure. The label separation was enforced operationally: only the controller read the hidden table and each research assistant used current-task revealed observations.

Long campaigns exposed a reporting defect: legacy full HTML/JSON exports duplicate large contexts and can reach hundreds of MB or over 1 GB. The default report now uses bounded pages and exact compressed, deduplicated evidence. On the completed T7 run, a 956,786,075-byte legacy HTML became an 11,618,188-byte complete bundle with a 2,549-byte overview and a largest page of 334,117 bytes. Repeated identical export adds zero bytes; original databases and exports were preserved. See [export format, recovery and limits](../../docs/TRACE_EXPORTS.md). Browser interaction could not be verified in this host; static page/link/escaping and byte-exact evidence tests passed. The 32 MiB mailbox file cap is a transport bound, not a verified native-model token limit. Entire-role context growth and remote-provider token/window behavior remain limitations; only some research-resource selection paths have character caps.
