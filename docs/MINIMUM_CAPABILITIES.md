# 是否最小化完备？按任务判定，不按模型数量判定

本文件是工程范围判断，不是证明模型准确性的实验结论。

## 单／多位点突变与实测反馈

已有：LLM直接提出替换或组合、ESMC先验与特征、已测数据任务预测器、约束检查、
预算控制、候选批次、审批、测量导入、工作流试用、Meta策略后继验收。
在限定替换空间、目标实测可用的条件下，这已能组成最小可运行研究闭环。
**不需要为了数量再加入ESM3、第二个PLM或结构生成器。**

仍需要实际数据验证预测质量、候选选择效果及RSI收益。实验失败与重测并不等于新增
独立标签。协议、数据划分及预算比增加模型数量更重要。

## 固定骨架重设计

ProteinMPNN + 一个结构预测器（这里选Protenix）+ 约束和结构对照，构成最小计算路线。
如果只是固定骨架重设计，RFdiffusion不是必需项。Rosetta是可选物理检查，不是许可未
取得时必须启用的依赖。

## 从头／针对靶点的Binder

RFdiffusion骨架 → ProteinMPNN序列 → Protenix复合物预测 → 显式链映射和结构检查，
可以构成最小计算候选链，但本版仅支持固定Binder长度与规定的蛋白输入范围。
**接口配置和离线仿真测试通过，不等于这条链已经完成真实模型端到端或湿实验验证。**
对完整性要求高的实验候选，CA几何检查还不足以代替全原子质量检查、表达与特异性
评估。可按目标增加Rosetta等验证，或经过校验的其它工具，而不是再并列多个生成器。

MSA：使用预计算A3M或明确MSA-free。如果要完整本地生成MSA，再加MMseqs2等数据库
搜索能力；本版只验证和接收已有MSA，不假装已经部署搜索数据库。

## 蛋白—蛋白定量亲和力

**不完备。** 结构置信度、CA接触、ESMC概率、Rosetta REU都不能直接当作已校准的Kd。
需要针对目标体系的实测亲和力、可靠的任务预测/校准及独立验证；实验体系和单位必须
明确。不能通过加一个通用打分器或修改字段名补上这个缺口。

因此当前不默认堆入Boltz、Chai、AF3、ESM3或其它重复路线。未来的新增工具必须说明：
它补的是哪个任务的哪项能力，而非“它比较新”。
